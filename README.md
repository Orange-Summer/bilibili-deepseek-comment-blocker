# 屏蔽 B站 DeepSeek AI 评论

一个用于整理 B 站视频评论区的油猴脚本：屏蔽指定账号，折叠命中文本规则的评论，支持暂停、撤销和名单备份。

**[前往 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/604358-%E5%B1%8F%E8%94%BD-b%E7%AB%99-deepseek-ai-%E8%AF%84%E8%AE%BA)** · [反馈问题](https://github.com/Orange-Summer/bilibili-deepseek-comment-blocker/issues)

## 安装

### 1. 安装脚本管理器

在电脑浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。

如果浏览器或扩展提示需要开启“允许运行用户脚本”，请按提示在扩展管理页开启。

### 2. 安装脚本

打开 [Greasy Fork 脚本页面](https://greasyfork.org/zh-CN/scripts/604358-%E5%B1%8F%E8%94%BD-b%E7%AB%99-deepseek-ai-%E8%AF%84%E8%AE%BA)，点击“安装此脚本”，在脚本管理器页面确认安装。

也可以手动安装：打开 [脚本源码](./bilibili-deepseek-comment-blocker.user.js)，复制全文，在 Tampermonkey 中新建脚本、替换示例代码并保存。

### 3. 打开评论区

刷新 B 站视频页或番剧播放页，滚动到评论区。脚本会自动运行，管理按钮通常位于每条评论的“回复”旁边；不兼容的布局会放在当前评论正文下方。

默认使用平衡模式，黑名单和自定义屏蔽词均为空。你可以先浏览效果，再按需添加账号或调整规则。

## 日常使用

| 操作 | 使用方法 | 效果 |
|---|---|---|
| 屏蔽账号 | 点击评论旁的“屏蔽此 UID” | 将当前评论作者加入黑名单 |
| 取消屏蔽 | 点击“移出黑名单” | 将该作者移出黑名单 |
| 查看折叠内容 | 点击“展开原文” | 临时展开当前评论；可再次折叠 |
| 暂停或恢复 | 点击 Tampermonkey 图标 → 本脚本 →“暂停 / 恢复” | 暂停过滤时仍可使用名单管理按钮 |
| 查看统计 | 点击 Tampermonkey 图标 → 本脚本 →“当前扫描状态” | 查看已读取、已折叠和已拦截的数量 |

**账号黑名单与文本规则的显示方式不同：**

- 黑名单账号的评论会在受支持的评论响应中移除，不显示占位；已经显示出来或未被拦截的评论会用页面折叠处理。
- 文本规则命中的评论会在页面折叠，可以展开查看。
- 黑名单主评论被移除时，其整楼回复也不显示；正常主楼下的黑名单回复则单独移除。

### 如何找回被屏蔽的评论？

如果还能看到折叠摘要，可以直接展开或移出黑名单。

如果评论已经消失：先暂停脚本并刷新页面，再找到该评论，点击“移出黑名单”。也可以在设置中删除对应 UID，然后刷新页面。

暂停期间修改名单不会自动恢复过滤。恢复后，会按修改后的名单继续处理评论。如果账号移出黑名单后仍被折叠，请检查文本规则。

## 设置与备份

点击 **Tampermonkey 图标 → 屏蔽 B站 DeepSeek AI 评论 → 设置 / 导入导出 JSON**。

当前设置会显示为 JSON。修改后确认即可保存；取消则不修改。

| 字段 | 用途 |
|---|---|
| `enabled` | `true` 启用，`false` 暂停 |
| `mode` | 选择观察、平衡或严格模式，见下表 |
| `blockedUIDs` | 要屏蔽的账号 UID，使用带引号的字符串 |
| `blockedPhrases` | 要折叠的正文片段，忽略大小写；命中任意一项即可折叠 |
| `personaRules` | `true` 启用内置文本规则，`false` 关闭 |

### 屏蔽模式

| `mode` 的值 | 模式 | 效果 |
|---|---|---|
| `observe` | 观察 | 不从响应中移除评论，也不折叠；只标记页面命中，便于观察误伤 |
| `balanced` | 平衡（默认） | 拦截黑名单账号；自定义正文片段或较强的组合线索命中时折叠，其余弱线索只标记 |
| `strict` | 严格 | 拦截黑名单账号，扩大文本规则的折叠范围，可能误伤更多 |

内置规则使用昵称样式、人格自称等线索辅助判断，不能证明评论是否由 AI 或某个模型生成。普通 `@`、标点和昵称中的单字“鱼 / 鲸”本身不会触发规则。

### 配置示例

下面是空名单的默认配置，可复制后修改：

```json
{
  "enabled": true,
  "mode": "balanced",
  "blockedUIDs": [],
  "blockedPhrases": [],
  "personaRules": true
}
```

添加账号时，把 `blockedUIDs` 改为类似 `["123456789", "987654321"]`，示例数字请替换成实际 UID。UID 可以从作者主页 `https://space.bilibili.com/数字UID` 中找到；它与昵称不同，账号改名后仍然有效。

添加屏蔽词时，把 `blockedPhrases` 改为类似 `["不想看到的固定句子"]`。JSON 需要使用英文双引号，最后一项后面不要加逗号。

**只按账号过滤：** 将 `personaRules` 设为 `false`，并将 `blockedPhrases` 留为 `[]`。

**备份：** 复制设置中的完整 JSON，保存为本地 `.json` 文件。

**导入：** 复制备份文件的全部内容，粘贴到设置对话框中并确认。导入会替换当前设置，不会自动合并黑名单；请先备份。

设置保存在脚本管理器本地存储中，刷新页面或重启浏览器后仍会保留。切换浏览器或设备时，可以通过 JSON 备份迁移。其他已打开的 B 站标签页请刷新后再使用新设置。

## 查看屏蔽数量

除了菜单中的“当前扫描状态”，还可以按 `F12` 打开开发者工具，进入 **Console / 控制台**，在过滤框输入：

```text
[B站评论屏蔽]
```

请确保控制台没有隐藏 Info 级别日志。启用、暂停、恢复、修改设置或统计变化时，会输出黑名单数量、页面当前折叠数量、响应累计移除数量等信息；统计不变时不会重复刷屏。

页面折叠数表示当前已加载内容中的折叠数量；响应累计数可能包含同一评论重复返回，不能把两者相加当成去重后的总数。刷新页面会重新计数。

## 常见问题

### 安装后没有效果

1. 确认 Tampermonkey 中的脚本已启用，并按浏览器提示允许用户脚本运行。
2. 确认打开的是电脑端视频页 `www.bilibili.com/video/…` 或番剧播放页 `www.bilibili.com/bangumi/play/…`。
3. 刷新页面并滚动到评论区，再查看“当前扫描状态”或控制台日志。
4. 如果读取数量为 0，可能是评论尚未加载或页面结构变化；如果读取数量正常但没有折叠，也可能是没有命中规则。
5. 暂时停用其他修改评论区或拦截评论的脚本，排查冲突。

仍有问题时，请到 [Issues](https://github.com/Orange-Summer/bilibili-deepseek-comment-blocker/issues) 提供浏览器、脚本管理器、脚本版本、复现步骤和相关报错。

### 为什么评论总数与可见条数不同？

页面总数仍可能包含已被脚本屏蔽的评论，因此可见条数可能较少，也可能出现空的一页或空回复列表。

### 是否会影响我的 B 站账号？

脚本只改变本浏览器中的评论显示，不修改 B 站账号黑名单，不发送评论、不点赞、不上传评论，也不额外调用模型服务。控制台统计不会输出 UID 清单、用户名或评论正文。

## 适用范围

- 面向电脑端 B 站视频页和番剧播放页，不覆盖动态页、空间页、手机客户端或弹幕。
- 使用 Tampermonkey；其他脚本管理器和浏览器组合尚未完整验证。
- B 站页面或评论接口改版、注入时机及其他扩展可能影响效果，不能保证所有黑名单评论完全无闪烁。
- 名称表示过滤用途，脚本不能判断底层模型是否为 DeepSeek，也无法识别所有 AI 评论。
